# Student Performance Prediction System

A beginner-level machine learning project that predicts a student's **final score** (regression) and a **Pass/Fail** result (score >= 50) from study habits, attendance, past performance and background.

> **Note:** the dataset is **synthetic**, generated by `src/generate_data.py` (600 students). The model learns the pattern built into that script, not real student behaviour.

## Project structure

## How to run
```
pip install -r requirements.txt
cd src
python generate_data.py     # creates data/student_data.csv
python train.py             # cleans data, trains models, saves charts + model
python predict.py           # predict for a new student (interactive)
```
Then open `notebooks/Student_Performance.ipynb` (start Jupyter from inside the `notebooks` folder).

## Workflow
1. Generate data (600 rows, ~5% missing values in 3 columns)
2. Clean: remove duplicates, fill missing numbers with the median and categories with the mode
3. Explore: 8 visualizations, including a scatter plot of study hours vs score
4. Preprocess: imputer, StandardScaler, OneHotEncoder inside a scikit-learn Pipeline
5. Train and compare Linear Regression and Random Forest (80/20 split)
6. Evaluate with RMSE, MAE and R2, then derive Pass/Fail from the predicted score
7. Save the best model and predict for new students

## Results
| Model | RMSE | MAE | R2 |
|---|---|---|---|
| Linear Regression | 5.45 | 4.41 | 0.75 |
| Random Forest | 7.16 | 5.85 | 0.57 |

- **Best model:** Linear Regression
- **Pass/Fail accuracy** (threshold 50): 86.7%
- Strongest features: previous score, attendance and parental education
- Linear Regression beats Random Forest here because the data was generated from a mostly linear formula.
